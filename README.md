# 拍机助手 · TAO Spotter

> 全国民用机场拍机助手 —— 为飞友打造的安卓航班查询工具

一个专注于「拍飞机」场景的安卓 App：**支持全国 231 个民用机场**，打开即可看到当天到港 / 离港航班（航班号、航司、机型、注册号、计划/预计/实际起降时间），一键筛选「好货」（宽体机、稀有机型、国产大飞机、货机、特殊涂装），并配有完整天气、风向罗盘、飞机照片与特殊状态提醒。

**AI 生成的小工具** · 如有问题请反馈：**Lan_X86@outlook.com** · 感谢支持 🤝

## ✨ 功能特性

### 🛫 多机场支持（v4.2 新增）
- 内置**全国 231 个民用机场**（中文名 + 城市 + 三字码 + 四字码 + 坐标）
- 左上角机场按钮 / 右上角 ✈ 按钮 → 打开机场选择面板
- **搜索**：按城市（"杭州"）、机场名（"浦东"）、三字码（"HGH"）过滤
- **⭐ 收藏**：常用机场一键切换（默认收藏 青岛 / 北京 / 上海）
- **设为默认**：下次打开直接进入该机场
- 切换后航班列表、天气、ADS-B 半径、ATIS 提示、城市显示全部跟随新机场

### ✈️ 航班列表
- **到港 / 离港** 双列表，当天计划航班全览
- **按日期查询**：顶部日期栏可查前后 7 天；到港按**落地日期**、离港按**起飞日期**严格过滤
- **状态分组 + 可折叠**：`正在飞来` → `即将落地` → `时刻已过` → `地面` → `已落地` → `已取消` → `其他实时信号`
- **智能排序**：离现在越近越靠上；已过时刻的航班自动下移

### ⭐ 好货筛选
- 好货专页：即将到来（时间越近越上）→ 正在飞行 → 已落地/已起飞
- 标签：🟠 宽体 / 🟣 稀有 / 🔴 国产 / 🩵 货机 / 💗 涂装 / ⭐ 收藏
- 顶部统计「好货 N 架 · 宽体 x · 稀有 x …」

### ⚠️ 动态栏
- 🚨 紧急代码 7500/7600/7700、⚠️ 备降、❌ 取消、🌀 盘旋、⏱ 延误 ≥15 分
- 分「进行中 / 即将发生」与「已结束」两组

### 📷 详情页（FR24 全字段 + 照片）
- 飞机照片左右滑动轮播（planespotters，最多 10 张，失败可重试）
- 时刻表：起飞/落地 × 计划/预计/实际（每格带日期）
- 机场卡：中文城市 + 三字码 + 四字码 + 国家 + 时区 + 经纬度 + 全名
- 飞机：航班号（含备用号）、航司 + IATA/ICAO、机型中文 + 代码 + FR24 原文、注册号、注册国、呼号、ICAO 地址
- 实时位置：高度 / 地速 / 航向 / 垂直速度 / 距机场

### 🌤 天气与拍机辅助
- 天气卡：温度/体感/风向风速/能见度/降水/云量/日出日落/拍机指数 + 风向罗盘 + 跑道建议
- **ATIS 提示**：具体降落方向请用手台收听当地机场情报通波（青岛胶东 127.200 MHz）
- 点开：逐小时预报（12 小时）+ 未来 7 天天气播报；每 3 分钟自动刷新

### 🌏 机场城市中文名
- 三字码 + 拼音双映射：`Hangzhou→杭州`、`Harbin→哈尔滨`、`Tokyo→东京`…（约 180 条）

## 🚀 第一次使用

Flightradar24 数据源有 Cloudflare 人机验证：

1. 打开 App，若计划航班不显示，点空态页的 **「解锁 Flightradar24」**
2. 页面出现人机验证时手动勾选通过
3. 点「完成，重试数据」→ 之后 1~2 天无需再次解锁

如长时间不显示航班，可尝试开启 **VPN** 后点刷新（FR24 对部分网络有限制）。

## 🔧 技术架构

```
WebView 壳（Java，无 AndroidX 依赖）
├── assets/app/index.html   界面骨架
├── assets/app/app.css      深色航空主题
├── assets/app/app.js       全部业务逻辑
├── assets/app/airports.js  全国 231 个机场数据（中文名 + 坐标）
├── 原生异步网络桥 AndroidNative.httpGet/httpPost/httpGetBase64
│   ├── 自动携带 WebView Cookie（通过 FR24 的 Cloudflare 验证）
│   ├── 异步回调 window.__nativeCb（不阻塞 UI）
│   └── UA / 超时 / 重定向处理
└── 构建：javac → d8 → aapt2 → jar → zipalign → apksigner（无需 Gradle）
```

### 数据源

| 数据源 | 提供内容 | 说明 |
|---|---|---|
| Flightradar24 机场时刻表 | 全天计划时刻、机型、注册号、状态、机场信息 | 唯一航班计划源，需浏览器 Cookie 过 Cloudflare |
| adsb.lol / OpenSky | 机场周边实时飞机（机型/注册号/高度/速度/Squawk） | 仅「今天」显示，半径 200km |
| adsbdb.com | 注册号/HEX → 机型、呼号 → 航司 | 免费接口，内置限流与缓存 |
| Open-Meteo | 当前天气 + 8 天预报 + 逐小时 | 免费无密钥，按所选机场坐标 |
| planespotters.net | 按注册号查询飞机照片 | 免费接口（UA 需注明联系方式） |

开发者构建：

```powershell
# 需要 JDK 17 + Android build-tools 34 + platform android.jar
powershell -File gen-icon.ps1      # 生成图标（可选）
powershell -File gen-airports.ps1  # 生成全国机场数据（可选）
```

```powershell
node --check assets/app/app.js
```
