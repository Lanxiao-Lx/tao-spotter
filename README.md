## ✨ 三个核心亮点

### 🛫 一个 App，全国 231 个机场
- 左上角机场按钮 / 右上角 ✈ 按钮 → 打开机场列表
- **搜索**：输城市（杭州）、机场名（浦东）、三字码（HGH）都能找到
- **收藏**：常用的几个机场一键切换
- **设为默认**：下次打开直接进入该机场
- 切换后航班、天气、ADS-B 实时信号、ATIS 提示全部跟随

### ⭐ 好货一眼看穿
- 宽体机（A330/A350/B787…）、稀有机型（C919/ARJ21…）、国产大飞机、货机、特殊涂装、收藏
- 好货专页：即将到达 → 正在飞行 → 已落地/已起飞，时间越近越靠上
- 每个标签都有一句「为什么值得拍」的解释

### 🛰 未来 3 天一次存好
- 刷新时自动把**明天 / 后天 / 大后天**的完整航班抓下来存本地
- 切日期**秒开**，断网也能看
- 航班数据按日期归档，当天每个时段的数据会持续累积（弥补数据源缺口，详见下方说明）

## 📱 功能一览

### 航班列表
- 到港 / 离港双列表，状态分组可折叠：`正在飞来` → `即将落地` → `时刻已过` → `地面` → `已落地` → `已取消` → `其他实时信号`
- 按时刻临近排序；已过时刻的自动下移
- 卡片信息：大字时间 + 计划/预计/实际 + 落地/起飞标签、中文城市航线、航班号/航司、机型全称/注册号/倒计时/延误/实时高度

### 详情页（FR24 全字段）
- 飞机照片左右滑动轮播（最多 10 张，点击看原图）
- 时刻表：起飞/落地 × 计划/预计/实际（每格带日期）
- 机场卡：中文城市 + 三字码 + 四字码 + 国家 + 时区 + 经纬度 + 全名
- 飞机：航班号（含备用号）、航司 + IATA/ICAO、机型中文 + 代码、注册号、注册国、呼号、ICAO 地址
- 实时位置：高度 / 地速 / 航向 / 垂直速度 / 距机场

### 动态栏
- 🚨 紧急代码 7500/7600/7700、⚠️ 备降、❌ 取消、🌀 盘旋等待、⏱ 延误 ≥15 分
- 分「进行中 / 即将发生」与「已结束」

### 天气与拍机辅助
- 温度 / 体感 / 风向风速 / 能见度 / 降水 / 日出日落 / 拍机指数 + 风向罗盘动画 + 跑道建议
- **ATIS 提示**：具体降落方向请用手台收听当地机场情报通波
- 逐小时（12 小时）+ 未来 7 天预报，每 3 分钟自动刷新

### 中文体验
- 机场城市中文名：`Hangzhou→杭州`、`Harbin→哈尔滨`、`Tokyo→东京`…（约 180 条）
- 机型中文全称：`73F→波音737-800F 货机`、`32N→A320neo`、`789→787-9`…

## ⚠️ 为什么航班数量和真实数据有差距？（重要，请读）

FR24 免费接口有两个硬性限制，直接导致数量偏少：

| 现象 | 原因 | 本 App 的应对 |
|---|---|---|
| 今天的**已落地 / 已起飞**航班看不到 | 接口只返回"还没完成"的航班 | **当日累积档案**：每次刷新把拿到的航班归档，随时间补齐今天 |
| **历史日期**（昨天/前天）查不到 | 接口对历史 timestamp 返回 HTTP 400 | 只保留本地档案里的历史数据 |
| 未来日期数据 | 接口正常返回**完整计划** | **未来 3 天预取**：一次刷新全部存好 |

> 想要"任意时刻都完整"的数据，只能使用**付费数据源**（FR24 官方 API / 飞常准开放平台等，需要 API key）。免费方案只能做到"今天未完成航班 + 未来 3 天完整 + 本地档案逐步补齐"。

## 🚀 第一次使用

1. 打开 App → 欢迎说明 → 「开始使用」
2. 若计划航班不显示：点「解锁 Flightradar24」→ 在页面里通过人机验证 → 返回点「完成，重试数据」
3. 刷新一次后，未来 3 天数据会在后台自动预取（约 20-60 秒）
4. 设置 → 数据源诊断 可查看：返回条数 / 档案累计 / 预取结果

如长时间不显示航班，可尝试开启 **VPN** 后刷新（FR24 对部分网络有限制）。

## 🔧 技术架构

```
WebView 壳（Java，无 AndroidX 依赖）
├── assets/app/index.html   界面骨架
├── assets/app/app.css      深色航空主题
├── assets/app/app.js       业务逻辑（含档案 / 预取 / 探测工具）
├── assets/app/airports.js  全国 231 个机场数据（中文名 + 坐标）
├── 原生异步网络桥 AndroidNative.httpGet/httpPost/httpGetBase64
│   ├── 自动携带 WebView Cookie（通过 FR24 的 Cloudflare 验证）
│   ├── 异步回调 window.__nativeCb（不阻塞 UI）
│   └── UA / 超时 / 重定向处理
└── 构建：javac → d8 → aapt2 → jar → zipalign → apksigner（无需 Gradle）
```

### 数据源

| 数据源 | 提供内容 | 说明 |
|---|---|---|
| Flightradar24 机场时刻表 | 计划时刻、机型、注册号、状态、机场信息 | 唯一航班计划源（免费接口只给未完成航班 + 未来完整计划） |
| adsb.lol / OpenSky | 机场周边实时飞机（机型/注册号/高度/速度/Squawk） | 仅「今天」，半径 200km |
| adsbdb.com | 注册号 → 机型、呼号 → 航司 | 免费接口，内置限流与缓存 |
| Open-Meteo | 天气 + 8 天预报 + 逐小时 | 免费无密钥，按机场坐标 |
| planespotters.net | 飞机照片 | 免费接口（UA 注明联系方式） |
