# 胶东拍机 · TAO Spotter

> 青岛胶东国际机场（TAO / ZSQD）拍机助手 —— 为飞友打造的安卓航班查询工具

一个专注于「拍飞机」场景的安卓 App：打开即可看到当天全部到港 / 离港航班（航班号、航司、机型、注册号、计划/预计/实际起降时间），一键筛选「好货」（宽体机、稀有机型、国产大飞机、货机、特殊涂装），并配有完整天气、风向罗盘、飞机照片与特殊状态提醒。

**AI 生成的小工具** · 如有问题请反馈：**Lan_X86@outlook.com** · 感谢支持 🤝

## ✨ 功能特性

### 航班列表
- **到港 / 离港** 双列表，当天计划航班全览
- **按日期查询**：顶部日期栏可查前后 7 天；到港按**落地日期**、离港按**起飞日期**严格过滤，次日航班不会混入
- **状态分组 + 可折叠**：`正在飞向青岛` → `即将落地` → `时刻已过（状态未更新）` → `地面` → `已落地` → `已取消` → `其他实时信号`
- **智能排序**：离现在越近越靠上；已过时刻的航班自动下移

### 好货筛选
- **好货专页**：即将到来（时间越近越靠上）→ 正在飞行 → 已落地/已起飞
- 标签判定：
  - 🟠 **宽体**：A330/A340/A350/A380、B747/B767/B777/B787、MD-11、伊尔-96 等
  - 🟣 **稀有**：C919、ARJ21、757、麦道系列、CRJ/ERJ、SSH100、伊尔-76、安-124 等
  - 🔴 **国产**：C919、ARJ21、新舟系列、运-12
  - 🩵 **货机**：顺丰、圆通、邮政、中州、龙浩、金鹏、国货航 + 国际货运航司
  - 💗 **涂装**：按注册号匹配内置涂装库（可自行增删）
  - ⭐ **收藏**：长按卡片收藏常拍的飞机
- 一键筛选：全部 / 宽体 / 稀有 / 国产 / 货机 / 涂装 / 收藏

### 特殊状态「动态」栏
- 🚨 紧急应答机代码 **7500 / 7600 / 7700**（红色闪烁）
- ⚠️ 备降、❌ 取消、🌀 盘旋等待（启发式识别）、⏱ 延误 ≥ 15 分
- 分「进行中 / 即将发生 → 已结束」两组，紧急优先、时间近的在前

### 详情页（FR24 全字段 + 照片）
- **飞机照片左右滑动轮播**（planespotters 图库，最多 10 张，点击看原图）
- **时刻表**：起飞 / 落地 × 计划 / 预计 / 实际，六时刻都带日期
- **机场卡**：中文城市名 + 三字码 + 四字码 + 国家 + 时区 + 经纬度 + 机场全名
- **飞机信息**：航司（含 IATA/ICAO/简称）、机型中文名 + 代码 + FR24 原文、注册号、注册国、呼号、ICAO 地址
- **实时位置**：高度 / 地速 / 航向 / 垂直速度 / 距机场
- 好货解读、拍摄建议、状态通俗解释、数据来源

### 天气与拍机辅助
- 天气卡：温度（渐变字）/ 体感 / 风向风速 / 能见度 / 降水 / 云量 / 日出日落 / 拍机指数
- **风向罗盘图**：跑道 16/34 与 17/35 方位 + 建议起降端
- 点开：逐小时预报（12 小时）+ 未来 7 天天气播报
- 日出日落黄金时刻提示；每 3 分钟自动刷新

### 其他
- 每次打开显示欢迎说明（AI 工具 / 反馈邮箱 / 源码 / 复刻提示词入口）
- 打开 App 显示 VPN 提示（FR24 在部分网络下需要）
- 离线缓存：断网也能看最后一次结果
- 深色航空主题，支持浅色/深色系统无所谓（固定深色）

## 🚀 第一次使用

Flightradar24 数据源有 Cloudflare 人机验证：

1. 打开 App，若计划航班不显示，点空态页的 **「解锁 Flightradar24」**
2. 页面出现人机验证时手动勾选通过
3. 点「完成，重试数据」→ 之后 1~2 天无需再次解锁

如长时间不显示航班，可尝试开启 **VPN** 后点刷新（FR24 对部分网络有限制）。

## 🔧 技术架构

```
WebView 壳（Kotlin/Java，无 AndroidX 依赖）
├── assets/app/index.html   界面骨架
├── assets/app/app.css      深色航空主题
├── assets/app/app.js       全部业务逻辑（约 110 KB）
├── 原生异步网络桥 AndroidNative.httpGet/httpPost
│   ├── 自动携带 WebView Cookie（用于通过 FR24 的 Cloudflare 验证）
│   ├── 异步回调 window.__nativeCb（不阻塞 UI）
│   └── UA / 超时 / 重定向处理
└── 构建：javac → d8 → aapt2 → jar → zipalign → apksigner（无需 Gradle / Android Studio）
```

### 数据源

| 数据源 | 提供内容 | 说明 |
|---|---|---|
| Flightradar24 机场时刻表 | 全天计划时刻、机型、注册号、状态、机场信息 | 主力源，需浏览器 Cookie 过 Cloudflare |
| adsb.lol / OpenSky | 机场周边实时飞机（机型/注册号/高度/速度/Squawk） | 仅「今天」显示 |
| adsbdb.com | 注册号/HEX → 机型、呼号 → 航司 | 免费接口，内置限流与缓存 |
| Open-Meteo | 当前天气 + 8 天预报 + 逐小时 | 免费无密钥 |
| planespotters.net | 按注册号查询飞机照片 | 免费接口（UA 需注明联系方式） |

### 内置映射表
- **机型代码 → 中文全称**（含 FR24 的 IATA 代码：`73F→波音737-800F 货机`、`32N→A320neo`、`789→787-9`、`33F→A330-200F 货机`…）
- **机场三字码 → 中文城市**（`HGH→杭州`、`HRB→哈尔滨`、`TAO→青岛`…约 140 条）
- **拼音/英文城市 → 中文**（`Hangzhou→杭州`、`Tokyo→东京`…约 180 条）
- **航司代码 → 中文名**（国内主要航司 + 常见国际航司 + 货运航司）
